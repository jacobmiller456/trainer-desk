TCG SET BROWSER

Browse sets and cards from the community-maintained Pokémon TCG API. Card images are served directly from their CDN.

▸ UPCOMING SETS
▸ RECENT TOURNAMENTS
Live API: card data pulls from api.pokemontcg.io/v2 (with api.tcgdex.net as an automatic backup); tournament results pull from Limitless TCG's public API (play.limitlesstcg.com/api) — the platform the competitive community uses for standings and decklists. Both work when the page is served over HTTP. Upcoming sets are hand-maintained — edit the UPCOMING_SETS array in the script whenever a new set is officially announced (via pokemon-card.com for Japan or official press for English). Sample data renders if a request is blocked (e.g. in a sandboxed preview).

POKÉDEX

Every species, searchable by name or number. Click one for types, base stats, and abilities.

Live API: species data pulls from PokéAPI (pokeapi.co/api/v2), a free community API that asks clients to cache responses — this page keeps the species list in session storage and each detail lookup in memory. Only factual fields are shown (names, types, base stats, abilities, size); Pokédex description text is not imported. Sample data renders if the API can't be reached.
